# Install with:

# Notes:
# - cardvec (../native/cardvec) replaces faiss-cpu: a small in-repo C++/
#   pybind11 library implementing just the one FAISS feature Binder used
#   (IndexFlatIP + normalize_L2 + read_index/write_index), so the app has
#   a build path to Android — real FAISS has no supported NDK build.
#   Install it with `pip install ./native/cardvec` (from the repo root)
#   before running scanner.py or build_scanner_models.py; see
#   native/cardvec/README.md for details, including cross-compiling for
#   Android.
# - cardnet (../native/cardnet) replaces ultralytics + torch + paddleocr +
#   paddlepaddle: an in-repo C++/pybind11 library that runs the same
#   trained YOLOv8/DINOv2/PaddleOCR models (each exported to ONNX once —
#   see native/cardnet/export/) via ONNX Runtime instead, since none of
#   those four frameworks have a supported Android/NDK build path and
#   ONNX Runtime does. Install it with
#   `pip install ./native/cardnet --config-settings=cmake.define.ONNXRUNTIME_ROOT_DIR=...`
#   (see native/cardnet/README.md) before running scanner.py or
#   build_scanner_models.py.

# pywebview's native window backend differs per OS:
# - Windows: uses the WebView2 runtime that ships with Windows 10/11 —
#   nothing extra to install.
# - macOS: needs pyobjc's Cocoa/WebKit bindings (pulled in below).
# - Linux: needs the GTK WebKit backend, which ALSO needs a system package
#   that pip can't install — see BUILD.md before building on Linux.
pywebview

pyobjc-framework-Cocoa; sys_platform == "darwin"

pyobjc-framework-Quartz; sys_platform == "darwin"
